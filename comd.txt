## 6. Save Changes to Git

Stage all changes:
```powershell
git add -A
```

Commit:
```powershell
git commit -m "Complete fresh push: all local files overwriting remote"
```

Push:
```powershell
git push origin main --force
```

**Warning:** `--force` can overwrite changes on the remote repository.

git add index.html style.css registry.js generateRegistry.js
git commit -m "Add gallery sorting and search"
git push origin main
